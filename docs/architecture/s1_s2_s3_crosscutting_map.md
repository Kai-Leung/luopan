# S1/S2/S3 横向架构图

| 横向层 | 当前代码职责 | 覆盖范围 | 已知限制 |
|---|---|---|---|
| S1 运行上下文 | 解析用户、组织、角色、项目范围并检查动作权限 | 业务路由通过 FastAPI dependency 统一挂载；H5/PC 传递受控请求头 | 当前 pytest 存在 `ContextVar` 跨线程重置失败，尚未达到全绿验证 |
| S2 治理闸门 | 校验必填、风险、阻断、补充和人工确认方向 | L1 候选进入 L2 前的统一治理与确认流程 | 部分候选解析断言仍失败；不得由前端复制或绕过 |
| S3 审计追溯 | 保存来源链事件并按事实或 trace 查询摘要 | L4-L7 持久化记录及反馈回流引用 | 自动化基线受 S1 测试失败影响，不能表述为完整验收 |

S1、S2、S3 是横向约束，不是可由某个页面或单一路由替代的独立业务阶段。
