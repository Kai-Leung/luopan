# S1/S2/S3 横向架构图

| 横向层 | 当前代码职责 | 覆盖范围 | 已知限制 |
|---|---|---|---|
| S1 运行上下文 | 解析用户、组织、角色、项目范围并检查动作权限 | 业务路由通过 async FastAPI dependency 统一挂载；H5/PC 传递受控请求头 | 自动化已验证线程上下文清理和越权阻断；完整账号体系仍未验收 |
| S2 治理闸门 | 校验必填、风险、阻断、补充和人工确认方向 | L1 候选进入 L2 前的统一治理与确认流程 | 自动化已验证主要正负路径；真实业务规则效果仍需人工验收 |
| S3 审计追溯 | 保存来源链事件并按事实或 trace 查询摘要 | L4-L7 持久化记录及反馈回流引用 | 自动化已验证来源链定位；运维审计流程仍未验收 |

S1、S2、S3 是横向约束，不是可由某个页面或单一路由替代的独立业务阶段。
