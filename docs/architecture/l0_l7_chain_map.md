# L0-L7 纵向链路图

```text
L0 原始输入
  → L1 候选
  → S2 治理闸门
  → 人工确认
  → L2 正式事实
  → L3 只读查询
  → L4 分析预览
  → L5 建议草稿
  → L6 执行响应记录
  → L7 反馈候选回流
```

边界：

- 只有通过 S2 且存在有效人工确认记录的请求可以进入 L2。
- L3 只读，不修改正式事实。
- L4 是预览，L5 是草稿，L6 是响应记录，均不得自动写 L2。
- L7 回到候选治理流，仍需重新经过治理，不直接修改正式事实。
- 当前代码包含上述 API、持久化记录和前端入口，但 pytest 基线并非全绿，
  因此不能把整条链路表述为已完成验收。
