# standard_governance

## 模块职责
提供标准字段、枚举、状态和基础校验函数的只读约束层。

## 目录分层
- `enums/`：来源类型、事实类型、状态类型等受控枚举。
- `rules/`：字段规则、事实记录类型分类规则、风险规则。
- `display/`：字段显示名、字段说明和反问模板映射。
- `validators.py`：只读校验函数，消费 `enums/`、`rules/`、`display/`。

旧兼容层已移除，业务代码应直接引用上述分层目录。

## 所属层级
主链路基础约束层，不属于 L0-L3 的业务处理层。

## 允许做什么
允许被 L0-L3 引用为字段、枚举、状态口径来源。

## 禁止越过什么
不得生成候选、治理结果、人工确认结果、正式事实或视图结果。
