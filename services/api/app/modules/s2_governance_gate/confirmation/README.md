# s2_governance_gate/confirmation

本目录是 S2 治理闸门下的人工确认子能力，不是独立业务模块。

它只负责接收 S2 输出的需确认/可确认候选，记录待确认事项、确认人、确认时间、确认结果，并向 L2 提供确认凭证。

禁止绕过 S2，禁止直接裁决正式事实，禁止前端伪造确认结果。

## 模块职责
记录人工对 S2 治理结果的确认、退回补充或拒绝动作。

## 所属层级
人工确认层，位于 S2 与 L2 之间。

## 允许做什么
允许消费 S2 结果并生成人工 review 记录；`confirmed_candidate` 仅表示可进入 L2 入链准备。

## 禁止越过什么
不得自动确认、不得写入 L2、不得生成正式事实。

上游为 `s2_governance_gate`；下游为 `l2_fact`。
