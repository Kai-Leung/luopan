# 00_开发依据包总览与阅读顺序

## 一、文件定位

本文是罗盘系统正式开发依据包的包级入口文件，用于承接整包阅读顺序、目录职责和跨目录承接关系。

## 二、阅读顺序

1. `10_顶层定义`
2. `20_系统架构`
3. `30_标准治理`
4. `40_业务数据体系`
5. `50_系统业务运行规则`
6. `60_接口边界与集成约束`
7. `70_前后端协同边界与页面承接`
8. `80_验证与验收规则`

## 三、目录职责

| 目录 | 目录职责 |
|---|---|
| `10_顶层定义` | 定义系统定位、系统边界、产品属性和阶段边界。 |
| `20_系统架构` | 定义系统层级、架构组成、读写边界、回流关系和架构依赖。 |
| `30_标准治理` | 定义术语、字段、枚举、状态、权限、风险、校验、追溯、反问、脱敏和 AI辅助与候选输出口径。 |
| `40_业务数据体系` | 定义对象资产层、事实记录层、汇总视图层和经验规则层的业务数据归口。 |
| `50_系统业务运行规则` | 承接系统运行链路、候选转正、状态流转、反馈回流和运行规则。 |
| `60_接口边界与集成约束` | 承接输入、输出、外部系统、页面动作和接口协同边界。 |
| `70_前后端协同边界与页面承接` | 承接页面展示、交互动作、状态提示、外部协同和前后端边界。 |
| `80_验证与验收规则` | 承接一致性检测、负向验证、回归验证和验收判断。 |

## 四、边界纪律

后续文件不得反向改写顶层定义、系统架构、标准治理和业务数据体系中已经确定的正式口径。后续目录只承接下游运行、接口、页面和验收细则，不反向定义上位文件。
