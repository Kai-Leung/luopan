# 00_前后端协同边界与页面承接总则

## 一、文件定位

本文定义罗盘系统前后端协同边界与页面承接的总口径，用于约束 H5、PC、外部协同页面在展示、录入、上传、补齐、候选处理、查询、输出、回执、失败提示、权限提示和追溯展示时，如何承接上游业务规则、接口边界和系统处理方向。

本文只定义页面层如何承接系统能力、接口返回、处理方向、权限边界、状态提示、追溯关系和下游页面分工，不定义视觉稿、页面布局、前端组件、交互细节、接口字段源、权限裁决源、业务模型源、验收规则来源、代码实现或实施计划。

页面可以展示信息、提示边界、收集输入、触发动作和承接处理结果，但不得反向定义字段、枚举、状态、权限、事实、接口、业务规则或后端裁决。

## 二、70 目录总职责

`70_前后端协同边界与页面承接` 的职责，是把已经由标准治理、业务数据体系、系统业务运行规则和接口边界定义的规则，转化为页面层可展示、可提示、可触发、可归口的承接边界。

70 目录承担以下职责：

1. 定义页面动作、页面状态、页面提示、接口调用、权限提示、追溯展示与系统规则之间的承接关系。
2. 约束 H5、PC 和外部协同页面不得反向定义正式事实、正式状态、正式权限、正式规则或接口边界。
3. 明确页面收到接口返回后，应展示为处理方向、待补原因、失败原因、回执结果、权限边界、追溯线索或可继续动作。
4. 明确页面展示的候选、待补、挂起、阻断、失败、回执、输出、熔断等内容，只能表达页面承接结果或接口处理方向。
5. 区分 H5、PC、外部协同页面在录入、查询、处理、展示、输出和协同中的承接边界。
6. 为 80 目录验证页面是否正确承接接口边界、权限边界、状态提示和追溯展示提供依据。

70 目录不是页面原型目录，不是前端实现目录，不是接口契约目录，不是权限规则目录，不是业务数据定义目录，也不是验收规则目录。

## 三、页面承接基本模型

页面承接应按以下模型组织：

| 页面承接环节 | 页面应处理的问题 | 页面不得承担的内容 |
|---|---|---|
| 页面收到什么 | 接收接口返回的处理方向、查询结果、候选内容、回执结果、失败原因、权限提示或追溯线索 | 不定义接口返回结构和字段来源 |
| 页面展示什么 | 展示用户可理解的处理方向、内容摘要、待补项、挂起原因、失败原因、输出范围或追溯入口 | 不把展示结果写成正式事实或正式状态 |
| 页面允许什么 | 允许用户继续录入、补齐、提交、确认、驳回、查询、查看、导出、反馈或等待处理 | 不绕过后端权限、状态、校验和确认 |
| 页面停止什么 | 停止越权展示、错误提示、重复提交、无效确认、未授权输出、外部误发和失败后继续推进 | 不以隐藏入口替代后端阻断 |
| 页面交给谁 | 将页面动作交给输入接口、页面动作接口、回执接入、失败回退、X1 外部连接或后续业务运行规则 | 不直接改写正式数据 |

页面显示“成功”“完成”“已处理”“已回执”“已生成”“已输出”等表达时，应以接口返回和上游规则为准，不得由页面自行解释为业务确认、事实成立或状态正式变更。

## 四、与上游目录的分工

| 上游目录 | 上游定义内容 | 70 承接方式 | 70 不得做的事 |
|---|---|---|---|
| 30_标准治理 | 术语、字段、枚举、状态、权限、风险、校验、追溯、反问、脱敏、AI 辅助与候选输出口径 | 页面按上游口径展示提示、状态方向、权限边界和候选属性 | 不重新定义字段、枚举、状态、权限、风险或校验 |
| 40_业务数据体系 | 对象资产层、事实记录层、汇总视图层、经验规则层及其真源边界 | 页面展示对象、事实、视图、经验规则候选或资料关系时，按层级边界表达 | 不把页面展示、汇总结果、导出包或外部反馈写成真源 |
| 50_系统业务运行规则 | 身份识别、访问范围、L0-L7 运行、横向治理、沉淀池与资料存储规则 | 页面承接待补、候选、确认、入链、回流、输出和失败处理方向 | 不替代业务运行规则作裁决 |
| 60_接口边界与集成约束 | 输入、外部映射、回执、失败、页面动作、联调和 X1 外部连接接口边界 | 页面按接口返回展示处理方向、失败原因、回执结果和归口入口 | 不定义接口协议，不绕过接口边界 |

70 的核心任务不是解释上游规则是什么，而是说明页面如何承接上游规则已经产生的结果、提示、入口和处理方向。

## 五、页面承接对象范围

页面承接对象包括以下类型：

| 页面承接对象 | 页面可展示或触发 | 页面不得表达为 |
|---|---|---|
| 原始输入 | 录入内容、上传内容、来源提示、待补提示、接收结果 | 正式事实 |
| 候选内容 | 候选对象、候选事实、候选资料记录、候选文件、AI 辅助预处理结果 | 正式事实、正式规则、自动放行结果 |
| 事实与入链结果 | 已入链事实、确认记录、证据链、版本、追溯关系 | 页面生成的事实 |
| 汇总视图结果 | 项目摘要、经营摘要、执行摘要、结算摘要、交付与协同摘要 | 新事实或真源数据 |
| 回执结果 | 接收、关联、失败、冲突、超时、撤回、纠偏、熔断等处理结果 | 客户确认、甲方确认、付款确认、验收确认 |
| 失败与异常 | 上传失败、识别失败、权限失败、外部提交失败、超时、重复、脱敏失败 | 业务否定结论或静默成功 |
| 权限与可见性 | 可见范围、不可见原因、脱敏结果、无权操作提示 | 页面自行裁决权限 |
| 追溯关系 | 来源、版本、证据、确认主体、处理记录、输出记录 | 页面补造的审计记录 |
| 外部协同内容 | 脱敏展示、外部反馈、外部确认线索、外部问题、处理方向 | 外部反馈直接成为正式事实 |
| Mock 或联调数据 | 演示结果、联调状态、模拟回执、测试提示 | 真实业务结果或正式数据 |

## 六、页面动作承接边界

页面动作包括录入、上传、补齐、候选处理、查询、导出、分享、外部反馈、状态查看和追溯查看等。页面动作只能触发接口或进入相应运行链路，不直接形成正式结果。

| 页面动作 | 页面收到或触发什么 | 页面应展示什么 | 页面允许什么 | 页面禁止什么 | 页面交给谁 |
|---|---|---|---|---|---|
| 录入提交 | 文本、语音转写、现场说明、备注、混合输入 | 已接收、待补、挂起、阻断或失败原因 | 继续补充、重新提交、等待处理 | 展示为事实成立 | 输入接口规范 |
| 上传资料 | 图片、文件、表格、资料包、截图、附件 | 上传结果、待补、不可读、重复、失败原因 | 补传、重新上传、关联候选资料 | 展示为资料有效或证据成立 | 输入接口规范、失败回退与熔断规则 |
| 反问补齐 | 项目、主体、资料、时间、责任、证据、说明补齐 | 补齐已接收、继续待补、重新处理 | 补充缺口、修改候选、等待校验 | 展示为正式确认完成 | 页面动作接口边界规则 |
| 候选处理 | 候选确认、驳回、修改、挂起、重新提交 | 候选处理方向、待补、阻断、后续处理 | 提交处理请求、查看原因、继续补齐 | 页面确认直接写入 L2 | 页面动作接口边界规则、系统业务运行规则 |
| 查询筛选 | 项目、主体、时间、资料、事实、视图、权限范围查询条件 | 权限范围内结果、空结果、无权提示、脱敏结果 | 调整范围、查看详情、进入追溯 | 返回越权数据或未授权原始输入 | 页面动作接口边界规则 |
| 授权输出 | 导出、分享、外部展示、生成分享包 | 生成中、输出成功、失败、撤回、熔断 | 查看输出范围、版本、接收对象 | 输出成功等于外部确认 | 页面动作接口边界规则、X1 接口控制总则 |
| 外部反馈 | 客户、甲方、供应商、班组、外部协作方反馈 | 已接收、待补、挂起、回流、人工处理 | 提交补充、查看处理方向 | 外部反馈直接改写真源 | X1 接口控制总则、回执接入规范 |
| 状态查看 | 处理方向、回执、失败、挂起、熔断、待补结果 | 当前处理方向和原因 | 查看详情、补齐、等待或返回上一步 | 展示为正式业务状态 | 页面状态与提示映射 |
| 追溯查看 | 来源、证据、版本、确认记录、操作记录、输出记录 | 可见范围内追溯信息 | 按权限查看、定位来源 | 页面生成或篡改追溯记录 | 事实入链与追溯展示页面映射 |

## 七、页面状态与提示边界

页面状态和页面提示用于帮助用户理解当前处理方向，不得创建新的正式状态体系。

| 页面可展示的处理方向 | 页面含义 | 不得误展示为 |
|---|---|---|
| 已接收 | 系统已接收输入、动作、回执或反馈 | 事实已成立 |
| 待补 | 当前信息不足，需要继续补充 | 系统已否定该事项 |
| 挂起 | 当前动作等待复核、回执、补齐或人工处理 | 事项已完成 |
| 候选 | 当前内容处于候选或待处理状态 | 正式事实 |
| 待确认 | 需要符合权限和状态要求的确认动作 | 已确认 |
| 已入链 | 上游规则已形成可展示的正式入链结果 | 页面完成入链 |
| 失败 | 当前接口动作失败 | 业务事实不成立 |
| 阻断 | 当前页面动作或接口动作不能继续 | 事实被最终否定 |
| 生成中 | 候选文件、清单、摘要或输出正在生成 | 正式文件已成立 |
| 生成成功 | 候选结果或输出材料已生成 | 外部主体已确认 |
| 回执已接收 | 回执进入系统并可关联处理 | 业务确认完成 |
| 撤回 | 已输出或已展示内容停止继续扩散 | 从未输出 |
| 纠偏 | 已处理结果被修正并保留原记录 | 原记录被删除 |
| 熔断 | 相关受控动作暂停 | 业务链路永久关闭 |
| 无权限 | 当前主体不可查看或操作该范围 | 数据不存在 |

页面提示应表达“当前能做什么、不能做什么、为什么不能继续、后续交给哪里处理”，不应表达未经上游确认的业务结论。

## 八、H5、PC 与外部协同页面分工

| 页面形态 | 承接重点 | 可承接内容 | 不承接内容 |
|---|---|---|---|
| H5 | 移动现场、快速记录、轻量查询、待补待确认、状态提示、外部协同入口 | 现场录入、资料上传、轻量摘要、待办、规则反问、外部反馈、个人相关事项 | 不承担完整 PC 管理工作台，不做复杂 BI，不直接写正式事实 |
| PC | 完整网页端展现形式和完整管理工作台 | 项目管理、资料管理、事实查看、复核确认、结算归集、外部协同管理、模板与规则资料、权限配置、系统状态摘要 | 不替代后端裁决，不替代完整 ERP、CRM、财务会计系统、复杂 BI 或运维平台 |
| 外部协同页面 | 客户、甲方、供应商、班组、外部协作方的脱敏展示、反馈和确认线索 | 脱敏查看、反馈提交、问题补充、资料上传、确认线索、状态提示 | 不承担完整客户门户，不让外部反馈直接入链 |

H5、PC 和外部协同页面应共享同一后端能力、同一数据口径、同一权限状态、同一事实链路和同一接口边界，不得形成多套事实口径、状态口径或资料归属口径。

## 九、权限、可见性与脱敏承接

页面权限与可见性承接应遵守以下规则：

1. 页面只承接后端返回的可见范围、不可见原因、脱敏结果和可操作边界。
2. 页面隐藏入口不能替代后端权限阻断。
3. 页面可见不等于接口可操作，接口可操作不等于业务可执行。
4. 页面展示客户、甲方、供应商、班组或外部协作方可见内容时，应承接脱敏、裁剪、授权范围和输出版本结果。
5. 页面不得展示未授权原始输入、未授权资料、内部成本利润、内部分析、审计明细或模型调用内部信息。
6. 页面不得根据角色名称、入口来源、前端缓存或历史上下文自行裁决权限。
7. 权限不足时，页面应展示受控处理方向，不得用空白、默认成功、假数据或本地缓存掩盖越权问题。
8. 跨组织、跨项目、跨主体、跨外部协同范围的数据访问，应以后端返回边界为准。

页面中的可见、不可见、部分可见、脱敏可见和禁止操作，均属于页面承接结果，不属于页面定义的正式权限。

## 十、追溯展示承接

页面追溯展示用于帮助用户查看事实、资料、候选、输出、回执和处理动作的来源关系，不得由页面生成或改写追溯记录。

页面追溯展示应至少区分：

| 追溯对象 | 页面可展示 | 页面不得展示为 |
|---|---|---|
| 输入来源 | 来源入口、提交主体、接收时间、原始内容引用 | 页面生成的事实依据 |
| 资料来源 | 资料本体、上传记录、归属线索、版本关系 | 资料已自动成为证据 |
| 候选来源 | 候选生成来源、缺口、补齐记录、处理方向 | 候选已正式成立 |
| 确认记录 | 确认主体、确认时间、确认动作、版本关系 | 页面自行确认 |
| 入链结果 | 已入链事实、关联对象、证据链、版本 | 页面写入事实 |
| 输出记录 | 导出、分享、展示范围、接收对象、输出版本 | 外部主体已认可 |
| 回执记录 | 回执来源、回执原文、关联动作、处理方向 | 业务确认完成 |
| 失败记录 | 失败原因、阻断、挂起、撤回、纠偏、熔断 | 业务终局判断 |

追溯展示应受权限控制。用户只能看到其权限范围内的追溯内容；超出权限的追溯细节应被裁剪、脱敏或隐藏，并展示受控提示。

## 十一、异常、失败与回执承接

页面不得把失败、异常、回执冲突、外部响应异常或熔断结果隐藏在前端提示层。凡涉及输入、上传、候选、确认、输出、外部协同、权限和追溯的失败，都应按接口边界承接。

| 接口或系统返回 | 页面应承接 | 页面不得承接为 |
|---|---|---|
| 上传失败 | 展示失败原因、补传方向或挂起提示 | 资料有效 |
| 识别失败 | 展示不确定项、待补或人工处理方向 | 正式内容生成 |
| 模板生成失败 | 展示缺口、失败原因或重新生成方向 | 正式文件成立 |
| 外部提交失败 | 展示外部发送失败、待回执或人工处理方向 | 对方已确认 |
| 回执超时 | 展示等待、挂起或处理方向 | 默认成功 |
| 权限失败 | 展示无权查看、无权操作或脱敏结果 | 数据不存在或业务完成 |
| 重复提交 | 展示疑似重复、已关联或待复核 | 已合并事实 |
| 外部展示异常 | 展示撤回、纠偏、熔断或人工处理方向 | 正常展示完成 |
| 熔断 | 展示相关受控动作暂停 | 业务链路关闭 |

页面应让用户理解下一步是补齐、等待、复核、撤回、纠偏、转人工还是重新提交，但不得把异常处理结果写成正式业务结论。

## 十二、页面与接口承接关系

70 页面承接必须服从 60 接口边界。涉及页面动作与接口动作关系时，按以下规则处理：

1. 输入、上传、导入和原始内容接收，归口 `60_接口边界与集成约束/01_输入接口规范.md`。
2. 外部字段、状态、编号、主体、分类进入页面展示前，归口 `60_接口边界与集成约束/02_外部系统映射规范.md`。
3. 候选生成结果、资料识别结果、模板生成结果、授权输出结果、外部响应和失败结果，归口 `60_接口边界与集成约束/03_回执接入规范.md`。
4. 上传失败、识别失败、权限失败、超时、重复、撤回、纠偏和熔断，归口 `60_接口边界与集成约束/04_失败回退与熔断规则.md`。
5. 页面录入、上传、反问补齐、候选处理、查询、授权输出、外部协同和状态查看，归口 `60_接口边界与集成约束/05_页面动作接口边界规则.md`。
6. 前后端联调、Mock 数据、页面展示与接口返回一致性，归口 `60_接口边界与集成约束/06_前后端联调约定.md`。
7. 外部系统、外部主体、外部协同反馈、外部回执和授权输出对象，归口 `60_接口边界与集成约束/07_X1_接口控制总则.md`。
8. 多文件归口、页面动作与接口边界关系不清时，归口 `60_接口边界与集成约束/08_接口边界承接总表.md`。

70 目录下的页面映射文件可以说明页面如何承接接口结果，但不得替代 60 目录定义接口边界。

## 十四、页面承接验收判断口径

70 目录输出的页面承接规则，应能支持 80 目录验证以下判断：

1. 页面是否只展示和触发动作，没有反向定义字段、枚举、状态、权限、事实或接口。
2. 页面是否把接口处理方向展示为处理方向，而不是展示为正式事实、正式状态或正式确认。
3. 页面是否正确区分原始输入、候选内容、正式事实、汇总视图结果、回执结果和外部反馈。
4. 页面是否在上传失败、识别失败、权限失败、外部提交失败、回执超时、重复提交和熔断时展示受控处理方向。
5. 页面是否未通过默认值、前端缓存、Mock 数据、最近上下文或外部字段补造正式内容。
6. 页面是否按权限范围展示查询结果、资料、追溯和外部展示内容。
7. 页面是否在 H5、PC、外部协同页面之间保持同一事实口径、状态口径、权限口径和接口边界。
8. 页面是否把 Mock、联调结果、候选文件、输出成功和回执成功与正式业务结果区分开。
9. 页面是否将问题归口到对应接口边界、业务运行规则、页面映射文件或验收断言，而不是在页面层临时处理。
10. 页面是否未写入视觉稿、前端代码、接口字段源、权限裁决源、业务模型源、验收规则来源和实施计划。

## 十五、禁止事项

70 目录及其下游页面承接文件禁止出现以下行为：

1. 禁止页面反向定义字段、枚举、状态、权限、事实类型、接口或业务规则。
2. 禁止页面动作直接写入正式事实。
3. 禁止页面确认、弹窗确认、状态提示或操作成功直接等同于 L2 真源入链完成。
4. 禁止上传成功、识别成功、模板生成成功、导出成功、分享成功或回执成功展示为业务确认完成。
5. 禁止页面用默认值、最近上下文、AI 推测、外部字段或 Mock 数据补造正式内容。
6. 禁止页面隐藏权限失败、上传失败、识别失败、外部提交失败、回执冲突或熔断结果。
7. 禁止页面越权展示原始输入、资料、追溯明细、内部成本、内部分析或未脱敏外部展示内容。
8. 禁止页面将外部反馈、外部确认线索、客户说明、甲方意见或供应商反馈直接展示为正式事实。
9. 禁止将 70 文件写成视觉稿、组件说明、交互设计、接口 schema、数据库结构、代码实现或实施计划。
10. 禁止通过页面承接文件新增系统能力、业务边界、架构层级、字段、枚举、状态、权限或事实类型。
