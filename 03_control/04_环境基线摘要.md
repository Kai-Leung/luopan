# 04_环境基线摘要

文件类型：Codex/Kodex 执行环境控制摘要  
来源：RUN_开发环境检查规则_双层机制.md  
用途：供 Codex/Kodex 执行基线体检、构建、测试和环境检查时读取。  

---

## 1. 定位

本文件不是正式开发依据正文，不放入 `02_development_basis/`。

本文件只用于执行环境检查，避免 Codex/Kodex 因找不到 RUN 文件而阻断。

---

## 2. 核心原则

- 技术选型按全阶段统一路线确定。
- 环境能力按阶段逐步启用。
- 全局底座检查在第一张基线体检任务中执行。
- 当前任务只检查当前阶段必需能力，不把后续能力作为当前阻断项。
- 本地开发环境和本地部署验证环境应分离。
- Codex/Kodex 不得修改 `.env`、密钥、正式数据库、Raw Store、storage 真实内容。
- 构建通过不等于验收通过。
- 执行器无报错不等于任务完成。

---

## 3. 全局底座检查项

| 检查项 | 要求 |
|---|---|
| Python | 应可支持 FastAPI 后端开发，并满足项目声明版本 |
| FastAPI | 后端 API 框架 |
| SQLAlchemy | 数据访问隔离层 |
| SQLite | 阶段验证数据库 |
| Node.js | 支持 React / Vite 前端开发 |
| React + TypeScript + Vite | 前端基础技术路线 |
| Git | 可检查 status 和 diff |
| 测试命令 | 应可建立或运行 |
| 构建命令 | 应可建立或运行 |
| `.env` | 不得进入 Git |
| `data/` | 不得提交真实数据 |
| `storage/` | 不得提交真实文件 |

---

## 4. 阻断与非阻断

### 必须阻断

- 缺少任务卡。
- 缺少 `AGENTS.md`。
- 缺少 `03_control/01_开发依据与目录映射总表.md`。
- 缺少 `03_control/02_任务卡索引与读取规则.md`。
- 缺少当前任务指定的正式开发依据。
- Python / Node 等版本低于项目声明要求，且当前任务需要运行对应环境。
- 需要修改 `.env`、真实数据库、Raw Store、storage 真实内容。
- 需要绕过 S2 直接写 L2。

### 不作为当前阻断

- 后续 PostgreSQL 未安装。
- 后续 Redis / Celery 未安装。
- 后续 Capacitor / 原生壳未启用。
- 后续部署环境未建立。
- 当前任务未涉及的能力未实现。

---

## 5. 回传要求

环境检查任务必须回传：

- Python 版本；
- Node.js 版本；
- 包管理器版本；
- Git 状态；
- 是否存在 `.env`；
- `data/`、`storage/` 是否存在真实内容；
- 依赖文件是否存在；
- 测试/构建命令是否存在；
- 当前阻断项；
- 后续非阻断项。
